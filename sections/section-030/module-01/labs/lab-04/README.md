# Generate A Namespace NetworkPolicy

Kyverno is ready without policies. New application namespaces need a NetworkPolicy generated by the background controller.

Allow about 15 minutes of learner work, plus startup and reconciliation.

```sh
astrona run -c sections/section-030/module-01/labs/lab-04
astrona submit -c sections/section-030/module-01/labs/lab-04
astrona destroy ats-021-lab-030-01-04
```

The task is in [question.md](question.md), with a [reference walkthrough](solution.md). Authors run `astrona validate -c sections/section-030/module-01/labs/lab-04` and `astrona test -c sections/section-030/module-01/labs/lab-04`. The lifecycle checks the unfinished state before applying the reference solution.

- A new namespace gets a default-deny NetworkPolicy.
