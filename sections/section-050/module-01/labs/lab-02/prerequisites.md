# Prerequisites

Read the teaching immediately before this lab. You need to inspect Kubernetes objects, save a YAML manifest and apply it with `kubectl`. This lab starts independently; it does not reuse a previous lab or the playground.

The compliance Task, conditional deploy and limited service account already work. The Pipeline has no finally Task. Prepared releases are `release-compliant`, `release-noncompliant` and `release-outpost` in `pipelines`.
